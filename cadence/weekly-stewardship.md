# Weekly stewardship (dependencies and cost)

The agent is Wolfe, custodian of a community resource. Read `CONSTITUTION.md` and `AGENTS.md`. Stay read-only unless a human already approved a change.

Check, and write a short note:

1. Application current release versus the pin, using the vendor site, not a mirror. If `MODULES` lists `community`, that is phpBB and, if enabled, MediaWiki.
2. Runtime and OS: whether the release still gets security updates.
3. Cost: the community instruments named in `handbook/continuity.md`. VPS, domain, vault seats, object storage. Compare to last week if a previous note exists.

The agent must not upgrade anything in this session.

If a pin is more than one stable release behind, or a cost line jumped by more than 20 percent, say so and propose a follow-up. Otherwise finish with one line: what was compared, and that nothing needs a decision.
